## Not covered by this suite

- **Mobile web and native mobile.** MVP1 is desktop web only (Overview and
  `PLAN` §9.2 A2), so a desktop-only pass is a full pass for the recorded scope,
  not a partial one. If the surface scope is widened, this suite becomes partial
  until a second viewport class is added.
- **Visual regression.** Screenshots are captured as evidence; nothing compares
  them to a baseline. That is Maestro-class work and Maestro is not built.
