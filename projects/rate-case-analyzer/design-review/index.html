Twelve screens, every state the product can be in

This is the rendered design proposal for the web surface and the ingestion job surface. Every page below is a real, static, self-contained render — open it from the file system or over a local server; there are no build steps, no external fonts and no network calls. The written proposal lives in knowledge/UX_KB.md; this is the part you can actually look at.

Read these three first, in this order

03 → 06 → 07. Screen 03 is the reference layout. Screens 06 and 07 are the two refusals that must never look alike: "we checked forty cases and none were comparable" versus "we checked nothing at all". If those two are confusable, the product has a silence-is-clearance failure and everything else is decoration. Screen 07 puts them side by side at the bottom of the page.

After that, 05 (the black-box settlement, and why "not stated" and "could not read it" are different components) and 12 (how sixteen document types and six claim statuses were made legible without ninety-six badges).

The web surface — answers

  • 03  Grounded answer — the reference screen Two authorized ROE figures with full citations, the coverage strip above the fold, the requested-not-granted card, comparability with every dimension matched, and provenance. Start here. F35 · F36 · F37 · F34 · F39 · F40
  • 04  Answer with caveats, stale precedent, a superseded order Named mismatched dimensions with both values, an unassessed dimension that is not counted as matched, a verbatim non-precedent clause, a superseded order shown and labelled, and a work-product source. Plus the all-cases-stale variant. F40 · F32 · AC-F36-07 · AC-F36-08 · AC-F27-10
  • 05  Black-box settlement — NOT_STATED "The settlement did not specify an ROE" rendered as an answer with a citation, not as a gap. Ends with the side-by-side that motivates it: NOT_STATED versus an extraction gap. AC-F36-02 · AC-F14-10 · AC-F14-11 · RCA-R5

The web surface — refusals, all first-class outcomes

  • 06  Refusal — 40 checked, none comparable The extrapolation trap, refused. Names the missing dimension combination, lists all forty examined cases with their exclusion reason, and is styled neutral — no red, no alert role, no error wording. F38 · AC-F37-04 · AC-F31-05/07 · RCA-R6
  • 07  Refusal — nothing examined The hardest design problem in the project. No bar at all: a dashed hatched band reading "Nothing was examined" with the filter values that produced the empty set. Side-by-side with screen 06 at the bottom. AC-F37-03 · AC-F31-08 · AC-F28-05 · RCA-R7
  • 08  Refusal — the question could not be resolved A slot-by-slot account of what was and was not understood. Says nothing about what the corpus contains, because nothing was looked for. No keyword-search fallback. AC-F38-07 · AC-F28-04 · ASM-11
  • 09  System failure, and the verification-failure refusal The only red in the product. Plus the third refusal cause — an answer that was composed, failed citation verification and was discarded whole. Ends with declined-vs-broken side by side. AC-F35-06 · AC-F38-06 · AC-F34-06

Corpus state and the second surface

  • 10  Corpus freshness banner — four states Fresh, stale with the age in days, a newer run that did not succeed (the as-of date never advances), and never-succeeded — which closes the answer path entirely. F39 · AC-F39-01…06 · RCA-R13
  • 11  Ingest run report — the job surface Quarantine reported with explicit zeros for every reason, confidential material quarantined with the marking text quoted as evidence, extraction gaps kept separate from quarantine, and the silent-stop health check. Plus the gate-failure variant. F42 · F43 · IND-10 · IND-11 · RCA-R11

  • 12  Components, tokens, and the 16 × 6 encoding How sixteen document types became four countable authority tiers and six claim statuses became three chip families — with the full precision kept as text. Things worth knowing before you judge this

Scope, honesty, and one environment constraint

  • Desktop web only. Mobile is recorded as out of MVP scope. The layout does not break on a narrow window — the rail stacks under the main column — but a narrow window is not the design target.
  • Light and dark both ship, via prefers-color-scheme. If your machine is in dark mode you are looking at the dark theme right now; both were designed, not one derived from the other.
  • Every figure, docket number, witness name and URL on these pages is illustrative. The docket-number formats are the real formats for each commission, and the URL shapes are the real URL shapes — that part matters, because they are what the citation card has to render. The values behind them are not represented as real filings.
  • No Figma, and none was faked. The available Figma account is a View-seat Starter plan: six MCP calls a month and no write access, so a design-system push was not attempted. These static pages are the deliverable and the reference implementation, which for this project is arguably the better artefact anyway — code-agent can read the markup directly. Recorded as an environment constraint in knowledge/UX_KB.md §7.
