Fluid adaptive desktop Increment 5 · replaces §10.2 fixed tiers

Human feedback on the §10.2 pass: desktop should be adaptive to screen for all four tabs — expand with content and available width (continuously, not in breakpoint jumps), never grow absurdly wide, and read as built for desktop, not a capped mobile column. Every frame below is a real iframe at 1024 / 1440 / 1920px running the exact proposed CSS — the fluid behavior you see is the behavior code-agent ships, not an illustration.
