Implementation note for code-agent (design spec, not code) — a shared <Lightbox photos={'{'}...{'}'} startIndex onClose/> component (new file, e.g. components/Lightbox.tsx) takes a flat list of {'{'} photoId, alt {'}'} plus a starting index, reused by both JourneyScreen.tsx (F15, list scoped to one memory's own photo_ids) and the F16 gallery (list scoped to every photo across the profile, chronological order) — one component, two different list scopes, satisfying the shared-lightbox requirement.
  • Trigger: every existing <img> in .lm-moment-banner / .lm-moment-photos gets wrapped in a new .lm-photo-trigger <button> (visually inert, all:unset) so it's keyboard-focusable and gives the lightbox a real element to return focus to on close.
  • Dismiss: the visible close button (44×44px, always present, fixed to the viewport corner not the image); Escape key; clicking the backdrop itself (event.target === event.currentTarget) — clicking the image or caption does not close it.
  • Focus: on open, focus moves to the close button; Tab/Shift+Tab stay trapped among the lightbox's own focusable controls (close, prev/next when present); on close, focus returns to the .lm-photo-trigger that opened it.
  • Keyboard nav: ArrowLeft/ArrowRight move within the current photo list; prev/next buttons and the dot indicator render only when the list has more than one photo.
  • Resolution: the lightbox's <img> reuses the exact same photoUrl(profileId, photoId) src already rendered as the thumbnail/banner — no new resize/thumbnail pipeline, no extra network request when the browser already cached it from the thumbnail load; crossOrigin="use-credentials" carried over unchanged.
  • Mobile vs. desktop: mobile caps the image at max-height:70vh so the caption and a safe dismiss margin stay visible without scrolling; desktop caps at 900px/76vh with the nav arrows sitting in the dark margin rather than overlapping the photo. Swipe-gesture navigation is a nice-to-have, not required for this pass — arrow buttons and keyboard arrows are the required affordance on every viewport.
