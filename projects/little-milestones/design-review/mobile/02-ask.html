Keyboard contract: the composer is pinned to the keyboard, not to the screen. Implemented with KeyboardAvoidingView (padding on iOS, height on Android with adjustResize); the message list is inverted so new messages appear at the bottom without a scroll-to-end race, and keyboardDismissMode="interactive" lets a parent swipe the keyboard away with the same thumb that is scrolling.
