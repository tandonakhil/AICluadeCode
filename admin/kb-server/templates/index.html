Using the Help menu

Help that can't drift out of date.

Type /help anytime to see what's actually available right now — it's read live from the platform's own agent and skill files, not a hand-maintained list, so it can never drift out of date the way a static README would. Not sure which command to run?

/help groups commands by what you're trying to do — start something new, change something existing, or ship what's ready.

03

Report an issue

How to report or fix an issue.

Where a problem goes depends on what kind of problem it is.

Bug in a project

Something's broken in code

Found inside a project's own Test/Review gate, fixed by code-agent, logged in that project's Decisions Log. This is the most common path — most real bugs get caught and fixed inside the normal pipeline, not reported separately.

Platform gap

The platform itself is missing something

Run /admin-panel propose-agent — mas-architect checks whether this is really new or overlaps an existing agent, then scopes it for your approval before anything is built.

/admin-panel propose-agent
Backlog item

Known, deliberately not built yet

Check admin/ROADMAP.md's Backlog section first — several real gaps are already scoped and just waiting for an actual trigger before they're built, on purpose.
